Installer « Remplir facture U »

Un favori qui remplit le formulaire Super U d'un seul geste.

1. Copier le code

2. Créer le favori sur iPhone

  1. Dans Safari, ouvre n'importe quelle page, touche Partager puis Ajouter aux favoris. Enregistre.
  2. Touche l'icône Signets (le livre) → Favoris → Modifier.
  3. Touche le favori que tu viens de créer.
  4. Renomme-le Remplir facture U.
  5. Efface l'adresse et colle le code copié à l'étape 1. Valide.

3. S'en servir

  1. Dans l'app, photographie le ticket puis touche Copier pour le formulaire.
  2. Ouvre magasins-u.com/ma-facture-u dans Safari.
  3. Touche la barre d'adresse, tape Remplir et choisis le favori.
  4. Si Safari demande l'autorisation de coller, accepte.
  5. Vérifie les valeurs, puis valide le formulaire toi-même.
Le bookmarklet ne valide jamais le formulaire. Il remplit seulement les cases : tu gardes le dernier mot avant l'envoi. Vérifie surtout le montant et la date, qui viennent d'une lecture de photo.
